An alarm clock with a Seeed Studio XIAO ESP32, a TFT display, and a piezo buzzer. The project includes firmware, a custom PCB, and a 3D-printed enclosure.


## Features

- Large clock display on a 320×240 TFT screen
- Piezo buzzer alarm with "WAKE UP!" visual alert
- 4-button interface for setting the alarm hour/minute
- Configurable alarm time with a simple state-machine UI
- Compact 90mm × 48.5mm PCB form factor
- Plays a unique melody for the alarm
